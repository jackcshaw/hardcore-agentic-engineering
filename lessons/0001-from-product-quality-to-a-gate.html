Lesson 1 · Define

From product quality to a gate

A larger test set does not rescue a test that measures the wrong thing. Application quality needs three decisions before the run.

1 · Claim

What must change?

Name an observable product behavior without prescribing the implementation.

2 · Instrument

What would reveal it?

Choose evidence that represents the behavior—not merely activity or compliance.

3 · Sample

Where must it hold?

Use cases the worker did not tune against, including one consequential failure case.

GAiDFLY already contains both layers

The existing 13-check transcript rubric tests process fidelity: turn discipline, responsiveness, concessions, closing sequence, no verdict, and other method requirements. That can establish that GAiDFLY behaved according to its method.

The same method document names the remaining gap: the rubric does not yet establish the product outcome—for example, whether the student's position became better tested or whether development sparring produced genuinely new material.

Perfect process fidelity can coexist with a session that did not help the student think.

A plausible real-repo task

Improve development sparring so abstract student claims are pressed toward concrete anchors without turning GAiDFLY into a tutor.

A contract for that task might combine:

  1. Behavior: after an abstract claim lacking an example, GAiDFLY requests or introduces a relevant concrete anchor within two turns.
  2. Method invariants: T1 turn discipline, T3 responsiveness, T8 no verdict, and T13 turn shape must remain green.
  3. Blind cases: held-out theses from several domains, including cases where the student already supplied a good example and GAiDFLY should not ask redundantly.
  4. Evidence: an independent reviewer cites the exact transcript turns supporting every pass or failure.
  5. Protected surfaces: the scenarios, judging rubric, thresholds, and docs/method.md stay outside the worker's write authority.
  6. Residual doubt: synthetic sessions and transcript judgments still do not prove that real students learn more.
