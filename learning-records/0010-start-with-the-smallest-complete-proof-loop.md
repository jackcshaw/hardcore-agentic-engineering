# Start with the smallest complete proof loop

Jack chose to reduce Project 1 from a broad GAiDFLY trusted-record feature to a small session-record application that can complete the full contract, brief, red check, worker, and independent-gate loop in one sitting.

The smaller task is still anchored in a real product boundary: GAiDFLY sessions are evidence of student learning, knowledge, and judgment. A missing historical snapshot must remain unknown; filling it from today's assignment would reconstruct history rather than preserve evidence.

## Evidence

The task uses three operator-owned cases: exact snapshot at creation, legacy readability without invented provenance, and refusal to overwrite an existing record.

## Implications

Project 1 optimizes for learning the method with an honest, bounded proof. GAiDFLY integration and the broader academic-record feature remain explicit blind spots rather than being smuggled into the first run.
