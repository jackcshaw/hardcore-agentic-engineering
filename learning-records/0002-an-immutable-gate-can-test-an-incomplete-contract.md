# An immutable gate can test an incomplete contract

Jack recognized that a correctly executed, unchanged gate can return a truthful pass over a scope too narrow to represent the intended outcome. Coverage and representative cases therefore belong in the pre-run definition of done, not as requirements invented after seeing the result.

## Evidence

Jack distinguished accuracy within the measured scope from genuine capability on novel cases.

## Implications

The next learning edge is construct validity: even broad coverage is insufficient if the instrument measures process compliance rather than the product outcome Jack actually cares about.
