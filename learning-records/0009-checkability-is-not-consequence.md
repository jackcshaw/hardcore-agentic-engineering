# Checkability is not consequence

Jack rejected invoice-ledger reconciliation as a Prove-It task because he is the ledger's only operator and manually reviews it. This correctly applies the Field Map's control dial: an excellent deterministic oracle does not justify a heavy harness when blast radius and irreversibility are low and human oversight is already cheap.

## Implications

Screen future candidates first for real consequence and delegation risk, then for independent checkability. Do not select a task merely because it is easy to test.
