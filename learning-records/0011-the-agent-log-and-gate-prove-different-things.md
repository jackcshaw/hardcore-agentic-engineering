# The agent log and gate prove different things

Project 1 produced a valid signed receipt for the contracted candidate, but its fresh worker also read Codex memory and a prior course rollout summary outside the supplied goal and rider.

## Evidence

The gate independently reran three protected cases and verified the fixed contract, test hash, and candidate tree. The saved worker task shows that its first information-gathering actions expanded beyond the two-file brief. The operator approved the plan without interrupting that expansion.

## Lesson

A gate receipt proves the named software result against the protected check. An agent log proves what information and actions produced that candidate. Neither substitutes for the other. A green gate cannot repair a contaminated cold-start claim, and a clean-looking trajectory cannot replace independent outcome evidence.

## Implications

Future cold-start riders and bet cards should name context expansion as an interrupt condition: no global memory, prior rollout summaries, or chat-derived files unless explicitly included in the brief. If the task requires those sources, list them as authorized inputs instead of calling the run cold.
