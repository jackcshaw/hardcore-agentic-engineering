# The first worker is the coding agent

Jack clarified that the first learning target should follow the course's software-building shape. The worker being judged is the coding agent manufacturing a new component. A product transfer is a later step, not the example needed to understand the build-and-gate method itself.

## Evidence

Greg's manufacture prompts ask an agent to build concrete harness components, then use operator-owned acceptance cases to judge the result. Jack recognized that both scoring a Socratic conversation and prematurely choosing a GAiDFLY feature distracted from learning the construction loop itself.

## Implications

First operate Greg's supplied fixture, then use a manufacture prompt to build a bounded component such as `contract-lint.mjs`. Transfer the pattern to another repository only after the build-and-gate loop is familiar.
