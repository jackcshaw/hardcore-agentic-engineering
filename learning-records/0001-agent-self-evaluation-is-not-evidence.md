# Agent self-evaluation is not independent evidence

Jack distinguishes an agent finishing its tool calls from the requested outcome being proven. He understands that the definition of done, metric, and passing threshold must be fixed by the judge before the run and protected from modification by the worker.

## Evidence

Jack identified metric weakening and outcome redefinition as concrete reward-hacking paths, and proposed an independently owned harness gate as the control.

## Implications

Future lessons can start with contract integrity, evidence provenance, and attacks on apparently passing gates rather than re-teaching why self-reported completion is unreliable.
